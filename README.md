# GeoExcel website
Plain HTML/CSS/JS – no build step. Open index.html, or upload the folder to any static host.
- Products, prices, shipping rules, contact details: js/data.js
- Payment: paste your Razorpay Key ID in js/data.js (config.gateway.keyId). Empty = demo payment sheet, nothing is charged.
  For production, create the order server-side and verify the payment signature on your server.
- Original photos and logo are in assets/ unchanged.
- Pack images: assets/packs/*.jpg are studio renders generated by tools/render (python3 build.py; needs numpy, opencv, pillow, scipy).
